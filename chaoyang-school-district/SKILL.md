# 朝阳区学区划片查询

## 数据来源

- 小学划片：http://xqcx.bjchyedu.cn/ （接口：`search2016.jsp`）
- 初中划片：http://xqcx.bjchyedu.cn/zh/ （接口：`searchz2016.jsp`，注意路径虽有 `/zh/`，但接口实际路径在根目录）

## 使用流程

### 第一步：模糊搜索，确认小区全称

用户给出的小区名可能是简称、别名、或与系统里的全称不完全一致（例如用户说"大西洋新城"，系统里实际存的是"广顺北大街33号院（大西洋新城）所有住宅楼"）。**必须先做模糊搜索**，不要直接假设全称。

```bash
python3 scripts/query.py --search "用户提供的小区名"
```

返回示例：
```json
{
  "candidates": [
    "广顺北大街33号院（大西洋新城）所有住宅楼",
    "南湖南路10号院（大西洋新城）所有住宅楼"
  ]
}
```

**处理规则：**
- 若 `candidates` 为空：告诉用户系统中未查到该小区，请确认名称是否准确，或换个说法再试（比如去掉"小区""家园"等后缀，或只用核心关键词）。
- 若只有 1 个候选：可直接进入第二步查询，无需再向用户确认。
- 若有多个候选（如上例的广顺北大街 vs 南湖南路）：**必须列出选项，询问用户确认具体是哪一个**，不要自行猜测选择，因为不同楼栋/院落对应的划片可能完全不同。

### 第二步：用确认后的全称查询划片结果

```bash
python3 scripts/query.py --query "广顺北大街33号院（大西洋新城）所有住宅楼"
```

返回示例：
```json
{
  "name": "广顺北大街33号院（大西洋新城）所有住宅楼",
  "primary_school": {
    "main": ["北京师范大学三帆中学朝阳学校"],
    "candidates": ["北京师范大学三帆中学朝阳学校", "北京市朝阳区花家地实验小学本部校区", "北京明远教育书院实验小学中园校区"],
    "duo_xiaopian": false
  },
  "middle_school": {
    "main": ["北京师范大学三帆中学朝阳学校"],
    "candidates": ["对外经济贸易大学附属中学（北京市第九十四中学）", "首都师范大学附属实验学校花西校区", "北京师范大学三帆中学朝阳学校"],
    "duo_xiaopian": false
  }
}
```

字段说明：
- `main`：该小区对应的主校（唯一对应校，通常就是划片结果）
- `candidates`：多校划片范围内的候选学校列表（可能包含 main 中的学校，也可能是多校划片池，最终以当年派位结果为准）
- `duo_xiaopian`：是否明确标注"多校划片"（true 时更应强调派位不确定性）

## 输出格式（重要）

汇总小学+初中两个结果，按以下格式呈现给用户（Markdown），**对应校加粗并单独换行**：

```
📍 【小区全称】划片查询结果

🏫 小学
对应校：
**主校名称**

多校划片范围内还可能派位到以下学校之一：
- 候选校1
- 候选校2

🏫 初中
对应校：
**主校名称**

多校划片范围内还可能派位到以下学校之一：
- 候选校1
- 候选校2

⚠️ 说明：该小区采用"多校划片、派位入学"方式（如适用），系统给出的是对应学校及可能派位范围内的候选学校，最终录取学校以当年教育部门实际派位结果为准，不是100%确定唯一学校。
```

**注意事项：**
- 若 `candidates` 列表去除 `main` 中的学校后为空（即没有额外候选校），则不显示"多校划片"段落，也不加免责说明，直接说明"该小区为单校划片，对应校为：**XX学校**"。
- 学校名称必须严格按接口返回原文，不要自行简化或改写校名（例如"三帆中学"不要写成"三帅中学"，务必逐字核对）。
- 若用户指出学校名称有误（识别/拼写错误），立即致歉并订正，不要辩解。
- 若接口返回 `success: false` 或抛异常，如实告知用户查询失败，并建议稍后重试或换个名称。

## 常见坑

- 该系统年份会更新（当前页面标题显示"2026年"），划片结果每年可能调整，若用户问及往年或次年数据，需说明本工具只能查当前系统里的现行数据。
- 小区名重名/相似名较多（比如带"佳园""佳苑"的院落很多），模糊搜索时优先展示地址前缀帮助用户区分（如"广顺北大街33号院"vs"南湖南路10号院"），不要只显示小区简称。
