# 差旅补贴计算器

## 补贴规则

```text
差旅补贴 = (机票全价金额 - 实际购买金额) × 20%
```

即：员工购买机票产生的折扣差价，公司按20%比例返还给员工作为差旅补贴。

## 使用方法

当用户提供以下信息之一，即可调用脚本计算：

**情况1：用户提供实际购买金额 + 折扣比例**（如“7折”、“打7折”或0.7）

```bash
python3 scripts/calc.py --price <实际购买金额> --discount <折扣，支持“7折”或0.7两种写法>
```

示例：用户说“我买了一张700元的机票，是7折买的”

```bash
python3 scripts/calc.py --price 700 --discount 7折
```

**情况2：用户提供实际购买金额 + 机票全价**（直接给出两个金额）

```bash
python3 scripts/calc.py --price <实际购买金额> --full-price <全价金额>
```

示例：全价1000元，实际花了700元：

```bash
python3 scripts/calc.py --price 700 --full-price 1000
```

## 计算逻辑

1. 若给出折扣比例：`全价 = 实际购买金额 / 折扣比例`
2. 差价 = 全价 - 实际购买金额
3. 补贴 = 差价 × 20%

## 注意事项

- 折扣比例支持小数（0.7）或“N折”（7折，等同0.7）。
- 折扣比例必须在 (0, 1] 之间。
- 若计算出全价小于实际购买金额，脚本会给出警告，需要与用户确认输入是否正确。
- 默认补贴比例为20%；如需调整，可用 `--rate` 参数（如 `--rate 0.5` 表示50%）。

## 输出

脚本会输出实际购买金额、机票全价金额、差价、补贴比例和最终补贴金额。计算结果应清晰呈现给用户。
